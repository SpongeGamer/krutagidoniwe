# Что удалить из репозитория

## Сначала главное: токен не утёк

Проверил напрямую — файла `cloudpub_token.txt` на GitHub **нет**, `.gitignore`
сработал. Беспокоиться не о чем.

Но в репозиторий попало несколько лишних файлов. Опасного среди них ничего нет,
однако убрать стоит.

## Команды для чистки

Открой терминал в папке с игрой и выполни по порядку:

```bash
git rm -r --cached .config .ssh backend/__pycache__
git rm --cached "Крутагидон Правила Игры.pdf"
git rm --cached "Крутагидон_база_карт.xlsx"
git rm --cached parse_cards.py run_sim.py
git add .gitignore
git commit -m "Убрал личные настройки и лишние файлы"
git push
```

`--cached` означает «убрать только из репозитория» — **с твоего компьютера
файлы никуда не денутся**.

## Что именно убираем и почему

| Файл | Почему |
|---|---|
| `.config/cloudpub/` | Личные настройки CloudPub с твоим `agent_id`. Токена там нет, но чужому это ни к чему |
| `.ssh/known_hosts` | Служебный файл SSH, попал случайно |
| `backend/__pycache__/` | Кэш Python, пересоздаётся сам |
| `Крутагидон Правила Игры.pdf` | **10 МБ** — самый жирный файл в репозитории. Правила и так у тебя есть |
| `Крутагидон_база_карт.xlsx` | Исходник таблицы. Все данные давно перенесены в `cards.json` |
| `parse_cards.py`, `run_sim.py` | Старые вспомогательные скрипты, игра их не использует |

После чистки репозиторий похудеет примерно на **10 МБ**.

## Про токен: теперь его невозможно закоммитить

Раньше токен лежал файлом рядом с игрой — и спасал только `.gitignore`.
Стоило его случайно удалить или добавить файл через `git add -f`, и ключ
уехал бы на GitHub.

Теперь токен хранится **вне папки игры**, в личных настройках Windows:

```
C:\Users\ТвоёИмя\AppData\Roaming\krutagidon\cloudpub_token.txt
```

Git туда не заглядывает в принципе. При первом запуске новой версии лаунчер
сам перенесёт токен на новое место и удалит старый файл — от тебя ничего
не требуется.

## Осталось запушить свежий код

В репозитории сейчас **v52**, а у тебя локально **v53**. Не доехали именно
те правки, ради которых всё затевалось:

- **keepalive** — браузер стучится на сервер каждые 20 секунд, чтобы туннель
  не рвал «молчащее» соединение. Это и есть лекарство от 502 в лобби;
- **ответ `ping` на сервере** — вторая половина того же механизма;
- **надёжное убийство cloudflared** — раньше он оставался висеть и мешал
  работающему туннелю;
- обновлённый `КАК ЗАПУСТИТЬ.md`.

Похоже, ты запушил за пару минут до того, как я закончил эти правки.
Просто закоммить ещё раз:

```bash
git add -A
git commit -m "Лечение 502: keepalive, чистка процессов, токен вне репозитория"
git push
```

Проверить, что доехало: открой на GitHub `frontend/app.js` и поищи
`BUILD_TAG` — должно быть `v53`.
