# Как запустить Крутагидон без помощника

## Windows — первый запуск

1. Установи **Python 3.11 или новее** с https://www.python.org/downloads/.
   При установке обязательно поставь галочку **Add Python to PATH**.
2. Скачай репозиторий кнопкой **Code → Download ZIP** на GitHub и распакуй его.
   Либо в VS Code сделай `git pull`.
3. Открой папку проекта в VS Code.
4. Открой терминал: **Terminal → New Terminal**.
5. Выполни по очереди:

```powershell
py -m pip install -r requirements.txt
py -m uvicorn backend.server:app --host 0.0.0.0 --port 8000
```

6. Открой в браузере:

```text
http://localhost:8000
```

Сервер работает, пока открыто окно терминала. Остановить: `Ctrl + C`.

## Быстрый повторный запуск

В терминале из папки проекта:

```powershell
py -m uvicorn backend.server:app --host 0.0.0.0 --port 8000
```

## Как играть с друзьями через интернет

Самый простой временный вариант — Cloudflare Tunnel.

1. В первом терминале запусти игру на порту 8000.
2. Во втором терминале выполни:

```powershell
cloudflared tunnel --url http://localhost:8000
```

3. Cloudflare покажет адрес вида:

```text
https://random-words.trycloudflare.com
```

Отправь его друзьям. Оба терминала должны оставаться открытыми весь вечер.

## Если порт 8000 занят

Запусти сервер на другом порту:

```powershell
py -m uvicorn backend.server:app --host 0.0.0.0 --port 8010
```

И открой `http://localhost:8010`.
