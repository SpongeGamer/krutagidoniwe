# Крутагидон Online

Браузерная версия настолки **Epic Spell Wars / Крутагидон** для игры с друзьями
через интернет. Без установки у игроков, без аккаунтов, без открытия портов —
хозяин запускает один файл и кидает ссылку в чат.

## Как играть

**Windows:** двойной клик по `ИГРАТЬ.bat`
**macOS / Linux:** двойной клик по `ИГРАТЬ.command`

Лаунчер сам поставит зависимости, поднимет сервер, откроет доступ из интернета
и напечатает готовую ссылку. Друзьям нужно только открыть её и написать имя.

Подробности, включая обход блокировок у российских провайдеров, — в файле
[`КАК ЗАПУСТИТЬ.md`](КАК%20ЗАПУСТИТЬ.md).

## Что реализовано

| Раздел | Состояние |
|---|---|
| Карты | **134 из 134** — все эффекты написаны |
| Беспределы | 20 из 20 |
| Мегабеспределы | 7 из 7 |
| Жетоны дохлого колдуна | 30 из 30 |
| Свойства колдунов | 10 из 10 |
| Защитные эффекты | 22 |
| Активируемые постоянки | 4 |

Полностью работают: колоды и рынок, покупки со скидками, отложенные атаки,
окно защиты от атаки, цепочки решений между игроками, лошара, главный приз,
вялые палочки, чипсины, подсчёт победных очков в конце партии.

### Интерфейс

- вход по ссылке, комната создаётся автоматически;
- автопауза, если игрок закрыл вкладку, — партия ждёт его возвращения;
- кнопка перерыва для всех;
- анимация полёта карт, звуки, извержение «БЕСПРЕДЕЛ!»;
- просмотр любой карты в лупу, список фамильяров и жетонов ЖДК;
- плашка свойства у каждого игрока — видно, кто с чем играет;
- экран итогов с разбивкой по очкам.

## Для разработки

```bash
pip install -r requirements.txt
python3 -m uvicorn backend.server:app --host 0.0.0.0 --port 8000
python3 -m pytest tests/ -q          # 180 тестов
```

### Структура

```
backend/
  game.py            движок: ходы, бой, смерть, подсчёт очков
  effects*.py        эффекты всех карт по реестрам
  server.py          WebSocket, комнаты, пауза, реконнект
  models.py          загрузка карт
frontend/
  index.html app.js style.css
launcher.py          автозапуск с туннелем
cards.json svo.json zhdk.json boards.json
```

Данные карт лежат в JSON и правятся без изменения кода: движок сам применяет
стоимость, мощь, победные очки и тип. В `effects*.py` дописывается только
текстовый эффект конкретной карты.
