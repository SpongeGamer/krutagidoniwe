# Крутагидон Online

Веб-версия настолки для игры с друзьями удалённо. Без БД, без аккаунтов —
партия живёт в памяти сервера, пока он запущен.

## Быстрый запуск (локально, для теста в одну вкладку/несколько вкладок)

```bash
cd krutagidon
pip install -r requirements.txt
uvicorn backend.server:app --host 0.0.0.0 --port 8000
```

Открой `http://localhost:8000` в браузере — несколько вкладок с разными
именами и одним кодом комнаты = несколько "игроков".

## Игра с друзьями, у которых нет VPN

Пробрасываем сервер наружу через **Cloudflare Tunnel** — бесплатно, без
открытия портов на роутере, без VPN:

```bash
# один раз: скачать cloudflared (https://github.com/cloudflare/cloudflared/releases)
cloudflared tunnel --url http://localhost:8000
```

Cloudflared выдаст ссылку вида `https://random-words.trycloudflare.com` —
её и кидаешь друзьям. Держать открытым нужно и `uvicorn`, и `cloudflared`.

Альтернатива без своего компьютера — задеплоить на бесплатный тир
Render.com / Fly.io (когда стабилизируем движок, сделаем инструкцию отдельно).

## Проверка без браузера (smoke-test)

```bash
python3 run_sim.py
```

Прогоняет партию случайными ходами ботов — если движок не упал и в конце
напечатался победитель, значит база не сломана.

## Структура проекта

```
krutagidon/
  cards.json          — 129 карт (сгенерировано из Excel-базы)
  zhdk.json            — 35 жетонов дохлых колдунов (30 ЖДК + 5 дохляков)
  svo.json              — 10 жетонов колдунских свойств
  boards.json            — 10 планшетов колдунов (имя ↔ фамильяр)
  parse_cards.py           — пересобирает *.json из исходного Excel
  backend/
    models.py               — Card dataclass, загрузка cards.json
    effects.py               — реестр текстовых эффектов конкретных карт
    game.py                    — движок: раунды, барахолка, урон, счёт
    server.py                   — FastAPI + WebSocket, комнаты в памяти
  frontend/
    index.html, app.js, style.css  — простой JS-клиент без сборки
  run_sim.py                        — smoke-test
```

## Что уже работает

- Подготовка партии: стартовые колоды, основная колода, колода легенд,
  барахолки (с корректной заменой Беспредела/Мегабеспредела на этапе
  подготовки без их розыгрыша — как в правилах).
- Ход целиком: розыгрыш карт → накопление мощи → покупка карт с барахолок
  и Шальной магии → покупка фамильяра за 6 мощи → конец хода → добор руки.
- Урон, смерть, воскрешение с жетоном ЖДК, главный приз Крутагидона.
- Три условия конца игры + подсчёт победных очков (ПО, штрафы за ЖДК,
  вялые палочки, лошару).
- Мультиплеер по WebSocket с живым состоянием на всех клиентов.

## Что пока не реализовано (осознанно, чтобы не блокировать первый playable)

- **Текстовые эффекты большинства карт.** Реализовано ~15 карт как пример
  паттерна (см. `effects.py`). Для остальных применяется только базовая
  механика (мощь/стоимость/ПО), а в лог пишется `[TODO] <карта> не
  реализована`. Догоняем инкрементально, по одной карте — архитектура уже
  готова, просто дописываем функции-обработчики.
- **Интерактивная защита от атак.** Сейчас атаки резолвятся сразу без
  возможности сыграть карту защиты в ответ. Это следующий кусок работы —
  нужен полноценный "стоп-кран" в цикле хода, ждущий ответа от целей атаки.
- **Лошара / жетоны колдунских свойств / фамильяры целиком.** Данные уже
  распарсены (`svo.json`, `boards.json`), подключение к движку — отдельный
  шаг.
- **Картинки карт.** Фронтенд сейчас чисто текстовый (hover показывает
  полный текст через `title`). Как только фото карт обрежете — подключим
  `photo`-путь из cards.json и покажем картинки вместо текста.
- **Хата Чипсодина, беспределы с голосованием/выбором** — сложные с точки
  зрения интерфейса, оставлены на потом.
